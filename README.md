# FIFO-conveyer

FIFO conveyer тестовое задание.

## Условие

Имеется кусок конвейера:

- `PB_1` – пуск/стоп (DI)
- 1 DO команда на привод без обратной связи
- Датчики `SO1` и `SO2` (2 DI)
- Отбраковщик (1 DO пушер без обратной связи)

## Структура продукта (объекта)

| Поле     | Тип        | Описание                                                       |
|----------|------------|----------------------------------------------------------------|
| `ID`     | `UDINT`    | При запуске конвейера начинаем с `1`, далее инкремент          |
| `Pos`    | `UINT`     | Присваивается по «внутреннему» энкодеру (например, инкремент каждый цикл PLC), внешний не предусмотрен |
| `Code`   | `STRING[20]` | Код продукта. Каждому пятому присвоить `NOREAD`, остальным – `GOOD` |
| `ErrorID`| `INT`      | Ошибка продукта                                                |

## Управление

- Нажали `PB_1` – конвейер включился.
- Еще раз нажали – выключился.

## Логика работы

Работает только при включенном двигателе:

1. По датчику `SO1` в очереди продуктов создается элемент, заполняются все характеристики, позиция берется по энкодеру.
2. По датчику `SO2` должна произойти проверка поля `Code` через 500 импульсов энкодера относительно срабатывания датчика `SO2`. На её основании продукт должен отбраковаться или проехать дальше. Удаляется элемент по принципу FIFO.
3. При переполнении очереди выдается ошибка (пока очередь является переполненной), конвейер останавливается.
4. Предусмотреть бит в программе для очистки всей очереди.

## Требования

При программировании использовать принцип ООП – вызов экземпляров FB, FC.
